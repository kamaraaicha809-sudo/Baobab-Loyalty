# Templates de structure par type de page

## 1. Article informationnel "Comment X"

```
H1 : Comment [verbe] [sujet] : guide [année]

[Hook : statistique ou question — 2-3 phrases]
[Promesse de l'article : ce qu'on va apprendre]
[Sommaire / table des matières si > 1500 mots]

H2 : Pourquoi [sujet] est important
  - Contexte rapide, chiffres clés
  - Enjeux pour l'audience cible

H2 : Étape 1 — [action]
  H3 : [sous-étape si besoin]
  - Concret, exemple, vérification

H2 : Étape 2 — [action]
H2 : Étape 3 — [action]
...
H2 : Étape N — [action]

H2 : Erreurs courantes à éviter
  - Liste de pièges

H2 : Outils recommandés
  - 3-5 outils

H2 : Pour aller plus loin
  - Liens internes vers articles cluster
  - CTA vers démo / essai

[Encart auteur + articles liés]
```

## 2. Page pilier (long-form)

```
H1 : [Mot-clé pilier] : guide complet [année]

[Introduction : 200-300 mots, qui résume tout le sujet]
[Sommaire avec ancres]

H2 : Qu'est-ce que [sujet] ? [définition]
H2 : Pourquoi [sujet] est-il important ?
H2 : Les types de [sujet]
  H3 : Type 1
  H3 : Type 2
  H3 : Type 3
H2 : Comment mettre en place [sujet]
  H3 : Étape 1
  H3 : Étape 2
H2 : Bonnes pratiques
H2 : Erreurs courantes
H2 : Outils & solutions
H2 : Études de cas
  H3 : Cas 1
  H3 : Cas 2
H2 : FAQ [Sujet]
  H3 : Question fréquente 1
  H3 : Question fréquente 2

[CTA fort en fin]
```

Longueur cible : 2500-4000 mots.

## 3. Comparatif "X vs Y"

```
H1 : [X] vs [Y] : quel est le meilleur en [année] ?

[TL;DR — qui gagne pour qui en 3 phrases]

H2 : Présentation rapide de [X]
H2 : Présentation rapide de [Y]
H2 : Comparaison fonctionnalités
  [Tableau comparatif détaillé]
H2 : Comparaison tarifs
  [Tableau de prix]
H2 : Comparaison support et onboarding
H2 : Avis utilisateurs
  H3 : Ce qu'on dit de [X]
  H3 : Ce qu'on dit de [Y]
H2 : Lequel choisir ?
  H3 : Choisis [X] si...
  H3 : Choisis [Y] si...

H2 : Notre recommandation
[CTA — démarrer essai]
```

## 4. Page produit / landing

```
H1 : [Bénéfice principal] avec [Marque]

[Sub-headline : promesse + preuve sociale]
[CTA principal — au-dessus du fold]
[Visuel produit ou démo vidéo]

H2 : [Bénéfice 1] (ex: "Lancez votre programme en 7 jours")
  - Bullet points fonctionnalités
H2 : [Bénéfice 2]
H2 : [Bénéfice 3]

H2 : Comment ça marche
  H3 : Étape 1 — [action utilisateur]
  H3 : Étape 2
  H3 : Étape 3

H2 : Ils nous font confiance
  [Logos clients + témoignages]

H2 : Cas d'usage par secteur
  H3 : Pour les commerces
  H3 : Pour les chaînes
  H3 : Pour les e-commerces

H2 : Tarifs
  [Récap rapide + lien vers /tarifs]

H2 : FAQ [Sujet]
  - 5-8 questions

[CTA final — démarrer essai gratuit]
```

## 5. Étude de cas

```
H1 : Comment [Client] a [résultat chiffré] avec [Marque]

[Encart : chiffres clés sur 3 colonnes]
[Photo + citation client]

H2 : À propos de [Client]
  - Secteur, taille, contexte

H2 : Le défi
  - Problème avant solution

H2 : La solution
  - Ce qui a été mis en place
  H3 : Phase 1 — [action]
  H3 : Phase 2 — [action]

H2 : Les résultats
  - Métriques détaillées avec graphiques

H2 : Ce que [Client] retient
  [Citation longue]

H2 : Conclusion et next steps

[CTA — réservez une démo]
```

## 6. Page tarifs

```
H1 : Tarifs [Marque] : un plan adapté à chaque taille d'entreprise

[Toggle mensuel / annuel]
[3 colonnes plans avec features et CTA]
[Comparatif fonctionnalités complet en tableau]

H2 : Comment choisir le bon plan
  - Aide à la décision

H2 : FAQ tarifs
  H3 : Y a-t-il des frais cachés ?
  H3 : Puis-je changer de plan ?
  H3 : Y a-t-il un engagement ?
  H3 : Comment fonctionne l'essai gratuit ?
  H3 : Acceptez-vous les paiements annuels ?

H2 : Témoignages
H2 : Comparatif avec les alternatives
[CTA fort]
```
