# Cheatsheet — Modificateurs FR par intention de recherche

## INFORMATIONNELLE — l'utilisateur cherche à comprendre

Modificateurs typiques :
- comment, comment faire, comment ça marche
- qu'est-ce que, c'est quoi, définition
- pourquoi
- guide, tutoriel, étapes
- exemple, exemples
- différence entre X et Y
- avantages / inconvénients
- liste, top, meilleur (sans intention d'achat directe)

**Type de page idéal** : article de blog long, guide complet, glossaire, vidéo tutoriel.

## NAVIGATIONNELLE — l'utilisateur cherche un site précis

Modificateurs typiques :
- nom de marque seul ("baobab loyalty")
- marque + connexion / login
- marque + dashboard / espace client
- marque + contact / téléphone
- marque + adresse

**Type de page idéal** : page d'accueil, page produit principale, page de connexion.

## COMMERCIALE — l'utilisateur compare avant d'acheter

Modificateurs typiques :
- meilleur, top, top 10, top 5
- comparatif, comparaison, vs, ou
- alternative à
- avis, avis clients, opinions, retour d'expérience
- review (anglicisme courant en B2B)
- recommandé, recommandation
- expert, professionnel

**Type de page idéal** : page comparatif, étude de cas, page "Pourquoi nous", landing avec démo.

## TRANSACTIONNELLE — l'utilisateur veut acheter / agir

Modificateurs typiques :
- acheter, commander, abonnement, abonnement à
- prix, tarif, tarifs, coût, combien ça coûte
- gratuit, essai gratuit, démo gratuite, version gratuite
- promo, code promo, réduction
- en ligne, livraison
- télécharger, installer, démarrer

**Type de page idéal** : page tarifs, page produit avec CTA, page démo, page checkout.

## Combinaisons fréquentes en B2B SaaS FR

| Intention | Pattern | Exemple |
|---|---|---|
| Comparaison concurrent | "X vs Y" | "baobab vs zerosix" |
| Alternative | "alternative à X" | "alternative à comarch loyalty" |
| Comparatif générique | "meilleur logiciel [catégorie]" | "meilleur logiciel fidélisation" |
| Tarif transparent | "[catégorie] tarif" | "logiciel fidélité tarif" |
| Open question | "comment [verbe] [domaine]" | "comment fidéliser ses clients" |
| ROI / business case | "[outil] roi" / "rentabilité [outil]" | "ROI programme fidélité" |
| Free trial | "[catégorie] gratuit" | "logiciel fidélité gratuit" |
