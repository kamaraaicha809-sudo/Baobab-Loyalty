# Commande /landing

Optimise le copywriting de la landing page Baobab Loyalty.

## Workflow

1. **Lire le skill** : Charger `.claude/skills/landing.md` pour suivre le processus
2. **Poser les 8 questions** (problème, cible, résultats, différenciation, preuves, objection, ton, action prioritaire)
3. **Analyser la landing page actuelle** dans `components/landing/*.tsx` et `config.js`
4. **Proposer le copywriting complet** en mode plan (Hero, Problème, Solution, Fonctionnalités, Témoignages, Pricing, FAQ, CTA final) avant de modifier le code
5. **Attendre validation** de l'utilisateur — il peut ajuster chaque section
6. **Appliquer le copywriting** dans le code une fois validé
7. **Lancer `npm run build`** pour vérifier que rien n'est cassé

## Règle absolue

Toujours parler du résultat obtenu par l'hôtelier, jamais des fonctionnalités techniques.
